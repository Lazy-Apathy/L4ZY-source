# Commands the settings assistant may propose (Settings > Assistant).
# Settings themselves (crosshairsize 30, gamma 110...) need nothing here:
# any setting of the menus or saved in config.cfg is already allowed, inside
# its own limits. This file lists the other commands.
#
#   cmd NAME ARGS | what it does | extra search words
#   action NAME ARGS | what it does | extra search words
#
# "action" = only allowed as what a key does (bind KEY action).
# ARGS: KEY (key name), ACTION (one allowed command or action), INT, NUM,
# WORD, TEXT, PAGE (a settings page); "?" = optional.
#
#   keyscript NAME | exact script | what it does | extra search words
#
# "keyscript" = a key action of the Keys page written as a small script: the
# assistant only writes NAME (bind V togglethirdperson) and the game binds the
# exact script given here, the same text as the Keys page (so the page shows the
# key). The game refuses a script that names quit, exec, alias, say, connect...
# Whatever this file says, the game never lets the assistant run quit,
# connect, exec, alias, say, writecfg and the like, nor any script.
# /assistantreload re-reads this file.

cmd bind KEY ACTION | put an action on a key (while playing) | touche touches clavier bouton assigner raccourci key keys shortcut
cmd specbind KEY ACTION | put an action on a key (while spectating) | touche spectateur spec clavier
cmd editbind KEY ACTION | put an action on a key in edit mode only (the edit keys of the Keys page) | touche edition editer clavier
cmd showgui PAGE | open a settings page | ouvrir menu page afficher
cmd cyclemycolor | change my own name colour to the next one | couleur nom pseudo
cmd settrailcolor WORD WORD WORD? | set a weapon trail colour: optional me / others / all (default all), then SG CG RL RI GL PI, then the colour as 6 hex digits (FF69B4 or #FF69B4), stock, or same (same as All) | trainee traine couleur arme fusil rifle tir moi autres
cmd trailcolorreset WORD? | put the weapon trail colours back to stock: all of them, or only me / others / all | trainee traine couleur defaut reinitialiser
cmd mixreset | put all sound mix sliders back to default | son mix defaut reinitialiser
cmd clearconsole | empty the console | console effacer vider
cmd GFX_profapply INT | RT profile (Graphics > Performance), sets every row: 0 Ultra (default, best); 1 High (same look, +10-20% fps: DLSS CNN, solid leaves, light NRD, still models); 2 Medium (+half sky, 3 lamps, adaptive rays, 1 soft ray); 3 Low (+2 lamps, 1 glow, no soft shadows: darker, fastest); 4 = Custom (rows changed by hand) | profil ultra haut high moyen medium bas low qualite rapide fps images seconde lent saccade fluide carte graphique gpu modeste faible petite performance image complete personnalise custom prereglage | now: GFX_profwhich
cmd hudedit | open the HUD editor: every part of the HUD gets a frame the player drags with the mouse (right click puts one back, Esc when done) | hud deplacer placer disposition glisser bouger interface ecran position
cmd hudlayoutreset | put every HUD part back in its original place | hud reinitialiser remettre position origine
cmd importsettingsmenu | open the page that imports keys, name, options, servers and friends from another client (Sauerbraten, p1xbraten, an older L4ZY client or any folder); the import itself is only done by the player | importer import reglages parametres ancien client sauerbraten vanilla recuperer copier reprendre touches perdus
